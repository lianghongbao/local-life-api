# docs/sql/

数据库脚本目录。

## 文件

| 文件 | 用途 |
|------|------|
| `init.sql` | **当前完整 schema**(用户、信息、商家、公告、轮播、管理员、评论、点赞、举报、审计日志),含默认管理员账号。dev / 新环境首次部署跑这一份 |
| `migrations/` | 增量迁移脚本占位目录。已部署的生产实例上线新变更时新增,但 `init.sql` 必须同步更新 |

## 使用方式

### 新环境 / dev

```bash
mysql -uroot -p < init.sql
```

跑完就有完整可用的库 + 默认管理员账号(密码见 `init.sql`,**上线后必须改**)。

### 已有线上实例

如果已上线的小城便利贴实例需要加字段 / 加表 / 改结构:

1. 写 `migrations/YYYY-MM-DD-<描述>.sql`,做的是 **append-only 追加式 DDL**(不 DROP 表,不修改老数据的列类型)
2. **同时把同样的变更同步进 `init.sql`**,让新部署依然能跑 `init.sql` 拿到一致结构
3. 线上实例跑 `migrations/` 里的新脚本,dev / 新环境跑 `init.sql`
